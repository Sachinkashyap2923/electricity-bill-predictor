Pipeline Architecture

End-to-End Prediction Workflow

How user inputs translate into an estimated electricity bill

1
Input Validation

Captures daily consumption, previous month, billing cycle, and tariff parameters with strict range checks.

2
ML Consumption Model

StandardScaler transforms features and feeds selected model (LR or RF) to predict monthly kWh.

3
Bill Calculation

Calculates Energy Charge (kWh × Rate), Fixed Fees, and Taxes/Surcharges transparently.

4
Persistence & Insights

Saves record to SQLite, categorizes usage (Low/Moderate/High), and updates real-time analytics.

Academic Project Scope & Estimation Notice

This project is designed as an academic demonstration for the Master of Computer Applications (MCA) curriculum. The machine learning models estimate monthly consumption from user-supplied average daily and historical data. Actual utility billing often uses tiered telescopic slabs, peak/off-peak Time-of-Day (ToD) tariffs, power factor penalties, and government subsidies. The calculations produced by this application should be used for budgeting estimations only.
